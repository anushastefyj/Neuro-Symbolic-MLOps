# Project Specification

**Model Class:** 
- Initially: Small fully-connected neural networks (FCN) with ReLU activations.
- Future: CNNs, ResNets.

**Property Class:**
- Robustness bounds ($L_\infty$ norm perturbations).
- Safety constraints (e.g., specific input domains map to specific output classes).
- Encoded in VNN-LIB format.

**Domain:**
- Toy synthetic 2D datasets.
- MNIST subset.
